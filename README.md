### 📘 Project Submission Instructions

Please make sure to include the following in your submission:

1. **Add a `README.md` file** to your project folder.
   Your README should contain:

   * 🔗 **Link to your demo video** (e.g., hosted on YouTube)
   * 🌐 **Link to your deployed version** of the application
   * ☁️ **Deployment details** — specify the platform and services you used (e.g. Google Cloud Platform, Cloud Run, Cloud SQL PostgreSQL, etc.)

2. **Create a new branch** in this repository for your submission.

3. **Upload all your project files** in a **single folder** within that branch.
